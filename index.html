Web Search Bot

Tìm kiếm web • Tạo API key • Sao chép prompt cho AI

1. Tạo API key

Tạo khóa riêng để gọi API tìm kiếm của dịch vụ này.

Chưa có key

Key chỉ được hiển thị lúc tạo. Hãy giữ bí mật và không gửi key vào prompt công khai.

2. Thử tìm kiếm

Tìm kiếm bằng backend Render, không cần Brave/Tavily key.

3. Prompt hướng dẫn AI sử dụng API

Sao chép prompt này và gửi cho AI đang hỗ trợ bạn lập trình/tích hợp. Prompt sẽ tự điền địa chỉ API và key hiện có.

Bạn cần tự triển khai backend lên Render Web Service trước. Không dán API key vào mã nguồn công khai trên GitHub.

Triển khai nhanh

  1. Đưa index.html lên GitHub Pages hoặc một website tĩnh.
  2. Đưa các file trong thư mục backend lên một repository (hoặc cùng repository).
  3. Tạo Render Web Service, chọn Python, Build Command: pip install -r requirements.txt, Start Command: gunicorn app:app.
  4. Trong Render Environment, đặt FRONTEND_ORIGIN bằng URL website GitHub Pages của bạn.
  5. Dán URL Render vào ô backend ở trên, sau đó tạo key và thử tìm kiếm.

Bản mẫu dùng DuckDuckGo HTML làm nguồn tìm kiếm miễn phí; dịch vụ tìm kiếm có thể giới hạn hoặc thay đổi HTML. Đây không phải API key của Google/Brave/Tavily.
