Web Search Bot

Tìm kiếm đa nguồn · API key · Prompt tích hợp AI

1. Kết nối backend

Nhập URL Render Web Service của bạn.

2. Tạo API key

Chưa có key

Khóa chỉ hiện một lần. Hãy lưu an toàn. Khóa này truy cập API của website, không phải khóa OpenAI/Brave.

3. Tìm kiếm web

Gộp và loại trùng kết quả từ nhiều nguồn miễn phí.

4. Sao chép prompt tích hợp AI

Prompt hướng dẫn AI gọi API, xử lý lỗi và hiển thị nguồn. Nếu không muốn đưa key vào prompt, hãy giữ placeholder rồi cấu hình key riêng.

Triển khai nhanh

  1. Đưa index.html lên repository frontend và bật GitHub Pages.
  2. Đưa nội dung thư mục backend lên repository backend.
  3. Tạo Render Web Service; Build: pip install -r requirements.txt; Start: gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 60.
  4. Đặt biến FRONTEND_ORIGIN bằng URL GitHub Pages; nên cấu hình DATABASE_PATH=/var/data/keys.db khi đã gắn Persistent Disk vào /var/data.
  5. Nhập URL Render ở trên, kiểm tra kết nối, tạo key và thử tìm kiếm.

Bản này kết hợp DuckDuckGo HTML, Wikipedia API và Google News RSS. Các nguồn miễn phí không có SLA; một nguồn lỗi thì những nguồn còn lại vẫn có thể trả kết quả.
