04

Prompt hướng dẫn AI sử dụng API

Tự sinh prompt có endpoint, header, cách gọi và quy tắc trích dẫn nguồn
Nhấn “Tạo prompt hướng dẫn” để tạo nội dung bạn có thể gửi cho AI lập trình hoặc cấu hình bot.

Prompt chỉ hướng dẫn AI cách tích hợp. Bot vẫn cần được cấp quyền gọi HTTP/API trong môi trường chạy của nó; chỉ sao chép prompt không tự cài đặt công cụ vào bot.
